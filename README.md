# 📊 Exploratory Data Analysis of Large-Scale Retail Transaction Data

A complete Exploratory Data Analysis (EDA) project on a large-scale retail transaction dataset using Python. This project analyzes customer behavior, product performance, sales trends, and revenue insights through statistical analysis and professional visualizations.

---

## 🚀 Project Highlights

- 📌 Analyzed **100,000+ retail transactions**
- 📊 Performed Univariate, Bivariate, and Multivariate Analysis
- 📈 Created professional business visualizations
- 📉 Conducted statistical analysis (Skewness, Kurtosis, Correlation)
- 📦 Generated actionable business insights
- 🤖 Prepared data for Machine Learning
